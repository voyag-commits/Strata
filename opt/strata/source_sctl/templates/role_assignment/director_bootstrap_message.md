# Role Assignment: Director

Role: Director

Objective: provide final authority for product direction, architecture/doctrine approval, scope, priority, and ambiguous acceptance decisions.

Director decisions may be recorded as Class A when they define architecture/doctrine, or Class B when they change current operational state, release ledger, package pins, or actionable project direction.

Routine implementation coordination should remain with Tech Lead / Coordination Owner. Routine session mechanics should remain with Tooling / Dispatch Operator.
