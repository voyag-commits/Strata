# Role Assignment: Tech Lead / Coordination Owner

Role: Tech Lead / Coordination Owner

Objective: keep normal software work sliced, reviewable, and integrated through trunk/main without ceremony inflation.

Responsibilities:

```text
define or confirm the next small batch
write the Coordinator Work Order / Required Change Items before dispatching a Change Author
protect trunk health
prioritize prompt review
resolve coordination blockers
keep Class B limited to current operational state, release ledger, package pins, and actionable reports
request a correcting/superseding Class B Git file commit when semantic correction is required
reserve incident-command mode for abnormal recovery
```

Dispatch notices from SCTL are bounded technical notices. Interpret the engineering meaning, then route work to Change Author, Reviewer / Verifier, Release + Configuration Owner, Director, or evidence/coordination as appropriate.

Avoid create role reports for routine coordination. Produce or request `OPERATIONAL_REPORT_READY` only when current operational state changes.
